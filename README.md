# 幻灵终端 · 主站

这是 **幻灵终端（LiteMask）** 的下载主站，也是 GitHub Pages 部署的官方入口。

## 关于幻灵终端

幻灵终端是一款安卓端的终端模拟器，支持 Java 代码运行、命令行执行与彩蛋互动。轻量、开源、免费。

## 主站地址

- **主站（GitHub Pages）**：https://nanci-dev.github.io/nanci-site/
- **副站（国内镜像）**：https://hl-35jf377.maozi.io

## 功能

- Java 代码运行
- 命令行执行
- 彩蛋互动（输入 `nanci` 触发烟花）
- 支持 Android 8.0 及以上
