## 项目简介

幻灵终端（LiteMask）是一款安卓端的终端模拟器，支持 Java 代码运行、命令行执行与彩蛋互动。轻量、开源、免费，致力于降低编程学习门槛，让老机型、低配机也能跑代码、学逻辑。

## 官网

- **主站（GitHub Pages）**：https://nanci-dev.github.io/nanci-site/
- **副站（帽子云）**：https://hl-35jf377.maozi.io

## 功能

- **Java 代码运行**：在终端里自由编辑 Java 代码并运行，实时查看输出结果
- **命令行执行**：支持 Shell 命令
- **彩蛋互动**：输入 `nanci` 触发烟花动画
- **轻量适配**：支持 Android 8.0 及以上，老机型也能用
