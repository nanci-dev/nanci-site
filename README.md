## 📖 项目简介

**幻灵终端（LiteMask）** 是一款专为安卓设备打造的轻量级终端模拟器，支持 Java 代码运行、命令行执行与彩蛋互动。

我们相信：**科技不再是高高在上，而是服务于人民。**

幻灵终端致力于降低编程学习门槛，让老机型、低配机也能跑代码、学逻辑。无需高配设备，无需复杂配置，打开即用。

### 为什么做这个项目
- **老机型友好**：很多编程工具只支持新设备，老机型被抛弃。幻灵终端支持 Android 8.0 及以上，覆盖绝大多数设备。
- **学习门槛低**：不需要电脑，不需要配置环境，手机上就能写代码、看结果。
- **完全免费开源**：不收费、不割韭菜、不藏私，代码全部公开。

### 适合谁用
- 想学 Java 逻辑的学生
- 玩机圈、搞机圈的爱好者
- 没有电脑、只有手机的学习者
- 想随时随地跑一段代码的人

## ⚡ 功能

- **Java 代码运行**：在终端里自由编辑 Java 代码并运行，实时查看输出结果
- **命令行执行**：支持 Shell 命令
- **彩蛋互动**：输入 `nanci` 触发烟花动画
- **轻量适配**：支持 Android 8.0 及以上，老机型也能用
- **开源免费**：MIT 协议，自由使用、修改、分发
